Starbird demo cheat sheet

Soft Serve onboarding demo. Chrome, light mode, window 1280px or wider.

Get in

  1. 1

    Open soft-serve-admin.displai.ai in Chrome.

    Login page.

  2. 2

    Sign in with Google (@displai.ai).

    Menus list, in your own workspace.

  3. 3

    Account menu (top right) → Reset Demo → Confirm.

    Toast with the number of items removed. Seeded Starbird menus and Lunch stay.

Import the brand

  1. 4

    On Menus, click AI Assistant in the list header.

    Assistant opens into a new conversation.

  2. 5

    Look above the greeting.

    Card with a sample board on the Default theme, plus Import your brand / Keep the default.

  3. 6

    Click Import your brand.

    Assistant asks for the website.

  4. 7

    Type starbirdchicken.com, send.

    Within about 2 seconds: sample board in Starbird’s colours, the colours, fonts and logo it found with their source pages, and Use this theme / Import a different theme / Keep the default.

  5. 8

    Click Use this theme.

    Confirmation block with a tick box and a disabled Use this theme button.

  6. 9

    Tick the box, click Use this theme.

    “This is now your workspace theme,” then it asks about the menu.

Build the menu from the till

  1. 10

    Type A lunch menu for Demo. It is all in our Toast till., send.

    Read from Toast card (42 items, 10 categories), then it asks what to call the menu.

  2. 11

    Type Lunch, send, click Accept.

    Chat moves right and the canvas appears. Board shows 4 Sandwiches and 4 Tenders, with the item strip below.

  3. 12

    In the strip, tick Starbird 2.0 (the fifth sandwich).

    9 rows. “Too many items for screen: Add Screen” above the board, “Over capacity” below it.

  4. 13

    Flip Show the photographs.

    Photos appear beside the sandwiches.

  5. 14

    Type wings in Search items, then clear it. Flip Show the items off, then on.

    Strip filters but the boards don’t move. Items off collapses the strip; on brings it back.

  6. 15

    Click Add Screen.

    Two boards side by side; pills read 2 screens.

  7. 16

    Tenders block → Screen dropdown → Screen 2.

    Tenders move to board 2 as a whole block.

Change it, then go back

  1. 17

    Type Take the Tenders off the board.

    One board left, pill reads 1 screen. The strip may lag; trust the board.

  2. 18

    Type Add the Salads.

    Salads land and the menu splits onto two screens by itself.

  3. 19

    Scroll up through the earlier replies.

    Each one has “Iteration N · Restore this version · Show.”

  4. 20

    Click Show on iteration 3.

    That draft opens in a popover.

  5. 21

    Close it, then Restore this version on iteration 3.

    “Your earlier draft is restored,” and the stage shows that draft.

  6. 22

    Click Portrait under Screen 1.

    Screen 1 goes portrait; Screen 2 stays landscape.

  7. 23

    Click Landscape, tick Seamless wall, drag Size, then click Fit.

    Gap and bezel go to zero, boards scale (never re-flow), Fit resets the size.

  8. 24

    Theme pill → No theme, then put it back.

    The template’s own look, then the brand again.

  9. 25

    Click Lock certain elements, then press Escape.

    Overlay opens; Escape closes it and leaves the assistant open.

Finish and see it on the wall

  1. 26

    Finish and see the menu → Save to library (name is prefilled as Lunch).

    Menu page with both screens, and Preview · Where it plays · Publish in the header.

  2. 27

    Click Preview.

    All screens, the canvas controls and a Store picker.

  3. 28

    Set Screens to 3.

    Three frames; the third says “This menu does not reach a screen this far along.”

  4. 29

    Switch Screen 1 to Portrait.

    A real portrait composition.

  5. 30

    Back to 2 screens and Landscape, then drag Size all the way right.

    300%, the wall scrolls, type stays sharp.

  6. 31

    Click Fit.

    Both boards fit, with gap and bezel.

  7. 32

    Tick Seamless wall.

    One flush wall.

  8. 33

    Set Columns to 1.

    One big board per row.

  9. 34

    Open Theme, pick No theme.

    The template’s own look.

  10. 35

    Theme → Import a theme from a website → starbirdchicken.com → Use this theme → tick → confirm.

    Boards redraw on the brand.

Reset

  1. 36

    Account menu → Reset Demo.

    Your work is gone; seeded content stays.

Watch for

  • Chat says “did not answer in time”: send the same message again.
  • One change per sentence in chat.
  • Don’t say “on a second screen.” Use Add Screen and the Screen dropdown.
